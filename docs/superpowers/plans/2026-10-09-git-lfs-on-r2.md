# Git LFS on Smith (R2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The hosted coordinator answers the git-lfs batch API at `/git/<project>.git/info/lfs` for every project in a workspace and keeps the objects in the `GIT` R2 bucket, proxied through the Worker by default and presigned straight to R2 once two secrets are set.

**Architecture:** A new Worker module `lfs-route.ts` reuses the git endpoint's authentication and asks the workspace Durable Object (DO) for per-object verdicts kept in a new `lfs_objects` table (`lfs.ts`). Bytes move either through the Worker (`r2-store.ts`, hashed in flight) or over SigV4 presigned R2 URLs (`r2-presign.ts`, WebCrypto only). Builds of projects that hold LFS objects get a `git-lfs` label requirement and a read ticket in a new `lfs` job-spec field, which the native agent turns into git config env.

**Tech Stack:** Cloudflare Workers + Durable Objects (TypeScript, vitest with `@cloudflare/vitest-plugin`), R2 binding and S3 presigned URLs, git-lfs batch API v1 "basic" transfer, C++17 native agent (Una engine), nlohmann JSON.

**Spec:** `docs/superpowers/specs/2026-10-09-git-lfs-on-r2-design.md`

## Review Focus

1. A batch that names the same oid twice (git-lfs never does, a script might): the second entry must get the same verdict, not a double quota charge. Test added to Task 2.
2. A `PUT` of an object whose row is already `ready` (a retried upload): answer 200 without touching R2, so a retry can never truncate a good object. Test added to Task 4.
3. A download batch from a read ticket bound to another project (`smith_git_…` minted for project A used on project B): 401/403, never a presigned URL for B. Test added to Task 2.
4. `Content-Encoding: gzip` on a proxied PUT (git-lfs can gzip uploads when `lfs.transfer.enablehrefrewrite`-style tweaks are set): the stored bytes and the hash are of the inflated body, and the size check uses the inflated length. Test added to Task 4.
5. The presigned-mode `verify` of an object whose stored length matches but whose hash does not (a tampered or wrong file uploaded by a valid credential): deleted and 422, never `ready`. Test added to Task 5.

```ts
// Git LFS on Smith: the record of large objects a workspace keeps in R2 (one row per project + oid) and the pure
// pieces of the batch API. Objects live at lfs/<workspace>/<project>/<oid> in the GIT bucket; a row is `pending`
// from the batch answer that allowed an upload until the bytes are verified, then `ready`.
import { fail } from './http';

export const OID = /^[a-f0-9]{64}$/;
export const LFS_MEDIA = 'application/vnd.git-lfs+json';
export const LFS_MAX_OBJECTS = 1000;
export const LFS_MAX_OBJECT_BYTES = 5 * 1024 * 1024 * 1024;      // R2's single-PUT ceiling
export const DEFAULT_PROXY_MAX_BYTES = 100 * 1024 * 1024;       // the Workers request-body limit on Free and Pro plans
export const LFS_EXPIRES_SECONDS = 3600;
export const LFS_PENDING_TTL_MS = 24 * 3600000;
export const DEFAULT_LFS_QUOTA_BYTES = 5 * 1024 * 1024 * 1024;
export const LFS_LABEL = 'git-lfs';                              // advertised by agents that have git-lfs installed

export const LFS_SCHEMA = `
  CREATE TABLE IF NOT EXISTS lfs_objects (repo_id TEXT NOT NULL, oid TEXT NOT NULL, size INTEGER NOT NULL, state TEXT NOT NULL,
    created_by TEXT NOT NULL DEFAULT '', created_at INTEGER NOT NULL, ready_at INTEGER, PRIMARY KEY (repo_id, oid));
`;

export type LfsState = 'pending' | 'ready';
export type LfsRow = { repo_id: string; oid: string; size: number; state: LfsState; created_by: string; created_at: number; ready_at: number | null };
export interface LfsObjectRequest { oid: string; size: number }
export type LfsVerdict = { oid: string; size: number; have: true } | { oid: string; size: number; upload: true } | { oid: string; size: number; error: { code: number; message: string } };

export function lfsKey(workspaceId: string, repoId: string, oid: string): string { return `lfs/${workspaceId}/${repoId}/${oid}`; }
export function lfsUrl(origin: string, repoId: string): string { return `${origin}/git/${repoId}.git/info/lfs`; }
export function lfsConfigSnippet(origin: string, repoId: string): string { return `[lfs]\n\turl = ${lfsUrl(origin, repoId)}\n`; }

// "340 MB", "5.4 GB": one decimal only when it is not zero, binary units named the way people say them.
export function formatBytes(n: number): string {
  const units = ['B', 'kB', 'MB', 'GB', 'TB'];
  let value = n, unit = 0;
  while (value >= 1024 && unit < units.length - 1) { value /= 1024; unit++; }
  const rounded = Math.round(value * 10) / 10;
  return `${Number.isInteger(rounded) ? rounded : rounded.toFixed(1)} ${units[unit]}`;
}

// The batch request body (docs/api/batch.md). `transfers` and `ref` are accepted and ignored: the answer is always the
// basic transfer. Anything but sha256 is a 422 for the whole request.
export function parseBatchRequest(body: unknown): { operation: 'download' | 'upload'; objects: LfsObjectRequest[] } {
  if (!body || typeof body !== 'object' || Array.isArray(body)) fail(422, 'invalid_body', 'The batch request must be a JSON object');
  const b = body as Record<string, unknown>;
  if (b.operation !== 'download' && b.operation !== 'upload') fail(422, 'invalid_field', 'operation must be download or upload');
  if (b.hash_algo !== undefined && b.hash_algo !== 'sha256') fail(422, 'invalid_field', 'Only sha256 object ids are supported');
  if (!Array.isArray(b.objects)) fail(422, 'invalid_field', 'objects must be an array');
  if (b.objects.length > LFS_MAX_OBJECTS) fail(413, 'too_many', `A batch names at most ${LFS_MAX_OBJECTS} objects`);
  const objects = b.objects.map(entry => {
    const o = entry && typeof entry === 'object' ? entry as Record<string, unknown> : {};
    if (typeof o.oid !== 'string' || !OID.test(o.oid)) fail(422, 'invalid_field', 'Each object needs a 64-hex sha256 oid');
    if (typeof o.size !== 'number' || !Number.isSafeInteger(o.size) || o.size < 0) fail(422, 'invalid_field', 'Each object needs a non-negative integer size');
    return { oid: o.oid, size: o.size };
  });
  return { operation: b.operation, objects };
}

export interface VerdictOptions { quotaBytes: number; proxyMaxBytes: number | null; who: string; now: number }

export class LfsStore {
  constructor(private readonly sql: SqlStorage) {}
  get(repoId: string, oid: string): LfsRow | undefined { return this.sql.exec<LfsRow>('SELECT * FROM lfs_objects WHERE repo_id = ? AND oid = ?', repoId, oid).toArray()[0]; }
  usage(repoId?: string): { objects: number; bytes: number } {
    const row = repoId === undefined
      ? this.sql.exec<{ objects: number; bytes: number | null }>('SELECT COUNT(*) AS objects, SUM(size) AS bytes FROM lfs_objects').one()
      : this.sql.exec<{ objects: number; bytes: number | null }>('SELECT COUNT(*) AS objects, SUM(size) AS bytes FROM lfs_objects WHERE repo_id = ?', repoId).one();
    return { objects: row.objects, bytes: row.bytes ?? 0 };
  }
  readyCount(repoId: string): number { return this.sql.exec<{ n: number }>("SELECT COUNT(*) AS n FROM lfs_objects WHERE repo_id = ? AND state = 'ready'", repoId).one().n; }
  // One verdict per requested object, in order. Download: have it or 404. Upload: have it (same size), 422 on a size
  // clash, 413 past a cap, else a pending row and permission to upload. The quota is checked once for the whole batch
  // (507), counting ready and pending bytes plus the new ones; a repeated oid is charged once.
  verdicts(repoId: string, operation: 'download' | 'upload', objects: LfsObjectRequest[], o: VerdictOptions): LfsVerdict[] {
    if (operation === 'download') {
      return objects.map(({ oid, size }) => {
        const row = this.get(repoId, oid);
        return row && row.state === 'ready' ? { oid, size: row.size, have: true } : { oid, size, error: { code: 404, message: 'Object not found' } };
      });
    }
    const charged = new Set<string>(); let needed = 0;
    const decided: LfsVerdict[] = objects.map(({ oid, size }) => {
      const row = this.get(repoId, oid);
      if (row?.state === 'ready') return row.size === size ? { oid, size, have: true } : { oid, size, error: { code: 422, message: `Object exists with a different size (${row.size} bytes)` } };
      if (size > LFS_MAX_OBJECT_BYTES) return { oid, size, error: { code: 413, message: 'Objects over 5 GB cannot be stored' } };
      if (o.proxyMaxBytes !== null && size > o.proxyMaxBytes) return { oid, size, error: { code: 413, message: `Objects over ${formatBytes(o.proxyMaxBytes)} need direct uploads to R2; see Settings → Large files` } };
      if (!row && !charged.has(oid)) { charged.add(oid); needed += size; }
      return { oid, size, upload: true };
    });
    const used = this.usage().bytes;
    if (needed && used + needed > o.quotaBytes) fail(507, 'quota', `Smith keeps ${formatBytes(o.quotaBytes)} of large files for this workspace; this push needs ${formatBytes(used + needed)}`);
    for (const v of decided) {
      if (!('upload' in v)) continue;
      this.sql.exec(`INSERT INTO lfs_objects (repo_id, oid, size, state, created_by, created_at) VALUES (?, ?, ?, 'pending', ?, ?)
        ON CONFLICT(repo_id, oid) DO UPDATE SET size = excluded.size, created_by = excluded.created_by, created_at = excluded.created_at WHERE lfs_objects.state = 'pending'`,
        repoId, v.oid, v.size, o.who, o.now);
    }
    return decided;
  }
  markReady(repoId: string, oid: string, size: number, now: number): LfsRow {
    this.sql.exec(`INSERT INTO lfs_objects (repo_id, oid, size, state, created_by, created_at, ready_at) VALUES (?, ?, ?, 'ready', '', ?, ?)
      ON CONFLICT(repo_id, oid) DO UPDATE SET size = excluded.size, state = 'ready', ready_at = excluded.ready_at`, repoId, oid, size, now, now);
    return this.get(repoId, oid)!;
  }
  forget(repoId: string, oid: string): void { this.sql.exec('DELETE FROM lfs_objects WHERE repo_id = ? AND oid = ?', repoId, oid); }
  // Pending rows older than `before`, removed; the caller deletes any object left in R2 under their keys.
  sweepPending(before: number): LfsRow[] {
    const rows = this.sql.exec<LfsRow>("SELECT * FROM lfs_objects WHERE state = 'pending' AND created_at < ?", before).toArray();
    this.sql.exec("DELETE FROM lfs_objects WHERE state = 'pending' AND created_at < ?", before);
    return rows;
  }
  // Rows of projects that no longer exist (`keep` says which ids still do), removed; the caller deletes their objects.
  sweepRepos(keep: (repoId: string) => boolean): LfsRow[] {
    const gone = this.sql.exec<{ repo_id: string }>('SELECT DISTINCT repo_id FROM lfs_objects').toArray().map(r => r.repo_id).filter(id => !keep(id));
    const rows: LfsRow[] = [];
    for (const id of gone) { rows.push(...this.sql.exec<LfsRow>('SELECT * FROM lfs_objects WHERE repo_id = ?', id).toArray()); this.sql.exec('DELETE FROM lfs_objects WHERE repo_id = ?', id); }
    return rows;
  }
}
```

```ts
export async function authenticateGit(request: Request, env: Env, challenge: Record<string, string>, reply: (status: number, message: string, headers?: Record<string, string>) => Response = text): Promise<GitAuth> {

  const parsed = credentialOf(request);
  if (!parsed) return { ok: false, response: await limited(env2.GIT_FAIL_RATE, ip) ? reply(429, 'Too many failed git requests; wait a minute') : reply(401, 'Sign in with a Smith token as the password', challenge) };

  if (await limited(env2.GIT_RATE, await hash(credential))) return { ok: false, response: reply(429, 'Too many git requests; wait a minute') };
```

```ts
// Authentication is the git endpoint's (authenticateGit). Objects move through this Worker (proxy mode, Task 4) or
// straight to R2 over presigned URLs (Task 5); this module answers the batch API and routes the rest.
import { authenticateGit, CHALLENGE } from './git-route';
import { HttpError, hash, readText } from './http';
import { LFS_MEDIA, LFS_EXPIRES_SECONDS, OID, parseBatchRequest, type LfsVerdict } from './lfs';

export const LFS_PATH = /^\/git\/([a-z0-9][a-z0-9-]{0,63})(?:\.git)?\/info\/lfs(?:\/(.*))?$/;
const LFS_CHALLENGE = { ...CHALLENGE, 'LFS-Authenticate': 'Basic realm="Smith"' };
const NO_CACHE = { 'Cache-Control': 'no-cache, no-store, must-revalidate', 'X-Content-Type-Options': 'nosniff' };
const MAX_BATCH_BYTES = 1024 * 1024;

export function lfsJson(value: unknown, status = 200, headers: Record<string, string> = {}): Response {
  return new Response(JSON.stringify(value), { status, headers: { 'Content-Type': LFS_MEDIA, ...NO_CACHE, ...headers } });
}
export function lfsError(status: number, message: string, headers: Record<string, string> = {}): Response { return lfsJson({ message }, status, headers); }

type Transfer = { href: string; header?: Record<string, string>; expires_in: number };

// Reads a Durable Object refusal into an LFS error, counting 401/403 against the client address.
async function refuse(response: Response, failed: (r: Response) => Promise<Response>): Promise<Response> {
  const error = (await response.json().catch(() => ({}))) as { error?: { message?: string } };
  const out = lfsError(response.status, error.error?.message ?? 'Request refused', response.status === 401 ? LFS_CHALLENGE : {});
  return response.status === 401 || response.status === 403 ? await failed(out) : out;
}

  const url = new URL(request.url);
  const match = LFS_PATH.exec(url.pathname);
  if (!match) return null;
```

```ts
// Streams a request body into R2: one put below PART_SIZE, else equal multipart parts; gzip is inflated first and the
// cap applies to the inflated bytes. With `sha256`, the bytes are hashed in flight (crypto.DigestStream) and an
// object whose digest differs from it is deleted before the error reaches the caller.
import { HttpError, fail } from './http';

export const PART_SIZE = 5 * 1024 * 1024;           // R2 multipart parts: all equal but the last, at least 5 MiB
export const MAX_PART_BODY = PART_SIZE + 1024;       // a machine's response part

export async function storeBody(bucket: R2Bucket, key: string, request: Request, cap: number, options: { sha256?: string } = {}): Promise<{ size: number; sha256: string | null }> {
  let stream = request.body;
  if (!stream) {
    if (options.sha256 && options.sha256 !== 'e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855') fail(422, 'hash_mismatch', 'Uploaded data does not match the object id');
    await bucket.put(key, new Uint8Array(0)); return { size: 0, sha256: options.sha256 ?? null };
  }
  const encoding = (request.headers.get('Content-Encoding') ?? '').toLowerCase();
  if (encoding === 'gzip' || encoding === 'x-gzip') stream = stream.pipeThrough(new DecompressionStream('gzip'));
  else if (encoding && encoding !== 'identity') fail(415, 'content_encoding', `Unsupported Content-Encoding ${encoding}`);
  const digest = options.sha256 ? new crypto.DigestStream('SHA-256') : null;
  const hasher = digest ? digest.getWriter() : null;
  const reader = stream.getReader();
  const chunks: Uint8Array[] = []; let buffered = 0; let total = 0; let part = 0;
  let upload: R2MultipartUpload | null = null; const parts: R2UploadedPart[] = [];
  const flush = async (last: boolean) => {
    if (!upload) {
      if (last) { await bucket.put(key, concat(chunks, buffered)); return; }
      upload = await bucket.createMultipartUpload(key);
    }
    parts.push(await upload.uploadPart(++part, concat(chunks, buffered)));
    chunks.length = 0; buffered = 0;
  };
  try {
    for (;;) {
      let next: ReadableStreamReadResult<Uint8Array>;
      try { next = await reader.read(); }
      catch { fail(400, 'bad_body', 'The request body was not valid ' + (encoding ? encoding : 'data')); }
      if (next.done) break;
      total += next.value.byteLength;
      if (total > cap) fail(413, 'too_large', `This request is larger than Smith accepts here (${Math.round(cap / 1048576)} MB)`);
      if (hasher) await hasher.write(next.value);
      chunks.push(next.value); buffered += next.value.byteLength;
      while (buffered >= PART_SIZE) {
        const whole = concat(chunks, buffered); chunks.length = 0; buffered = 0;
        const head = whole.subarray(0, PART_SIZE); const rest = whole.subarray(PART_SIZE);
        if (!upload) upload = await bucket.createMultipartUpload(key);
        parts.push(await upload.uploadPart(++part, head));
        if (rest.byteLength) { chunks.push(rest); buffered = rest.byteLength; }
      }
    }
    await flush(true);
    if (upload) await upload.complete(parts);
    let sha256: string | null = null;
    if (hasher && digest) {
      await hasher.close();
      sha256 = [...new Uint8Array(await digest.digest)].map(b => b.toString(16).padStart(2, '0')).join('');
      if (sha256 !== options.sha256) { try { await bucket.delete(key); } catch { /* best effort */ } fail(422, 'hash_mismatch', 'Uploaded data does not match the object id'); }
    }
    return { size: total, sha256 };
  } catch (error) {
    try { await reader.cancel(); } catch { /* already done */ }
    if (hasher) { try { await hasher.abort(); } catch { /* closed */ } }
    if (upload) { try { await upload.abort(); } catch { /* lifecycle rule aborts it */ } }
    throw error;
  }
}
function concat(chunks: Uint8Array[], size: number): Uint8Array {
  if (chunks.length === 1 && chunks[0].byteLength === size) return chunks[0];
  const out = new Uint8Array(size); let offset = 0;
  for (const chunk of chunks) { out.set(chunk, offset); offset += chunk.byteLength; }
  return out;
}
```

```ts
// SigV4 query-string presigning on WebCrypto, for R2's S3 endpoint (https://<account>.r2.cloudflarestorage.com/<bucket>/<key>).
// Presigning needs no call to R2: with the two R2 API-token secrets the coordinator hands git-lfs a URL and the bytes
// go straight to the bucket, so the Workers request-body limit no longer caps object size.
export interface SigV4Target { accessKeyId: string; secretAccessKey: string; region: string; host: string; path: string }
export interface R2Presigner { accountId: string; bucket: string; accessKeyId: string; secretAccessKey: string }

const encoder = new TextEncoder();
const hex = (bytes: ArrayBuffer) => [...new Uint8Array(bytes)].map(b => b.toString(16).padStart(2, '0')).join('');
async function sha256Hex(text: string): Promise<string> { return hex(await crypto.subtle.digest('SHA-256', encoder.encode(text))); }
async function hmac(key: ArrayBuffer | Uint8Array, text: string): Promise<ArrayBuffer> {
  const k = await crypto.subtle.importKey('raw', key, { name: 'HMAC', hash: 'SHA-256' }, false, ['sign']);
  return crypto.subtle.sign('HMAC', k, encoder.encode(text));
}
// RFC 3986 unreserved characters only; S3 wants each path segment encoded this way and '/' kept.
function encodeRfc3986(value: string): string { return encodeURIComponent(value).replace(/[!'()*]/g, c => '%' + c.charCodeAt(0).toString(16).toUpperCase()); }
function encodePath(path: string): string { return path.split('/').map(encodeRfc3986).join('/'); }

export async function presign(target: SigV4Target, method: 'GET' | 'PUT' | 'HEAD', expiresSeconds: number, now = new Date()): Promise<string> {
  const amzDate = now.toISOString().replace(/[-:]/g, '').replace(/\.\d{3}Z$/, 'Z');
  const date = amzDate.slice(0, 8);
  const scope = `${date}/${target.region}/s3/aws4_request`;
  const query: [string, string][] = [
    ['X-Amz-Algorithm', 'AWS4-HMAC-SHA256'], ['X-Amz-Credential', `${target.accessKeyId}/${scope}`], ['X-Amz-Date', amzDate],
    ['X-Amz-Expires', String(expiresSeconds)], ['X-Amz-SignedHeaders', 'host'],
  ];
  const canonicalQuery = query.map(([k, v]) => `${encodeRfc3986(k)}=${encodeRfc3986(v)}`).join('&');
  const canonicalRequest = [method, encodePath(target.path), canonicalQuery, `host:${target.host}\n`, 'host', 'UNSIGNED-PAYLOAD'].join('\n');
  const stringToSign = ['AWS4-HMAC-SHA256', amzDate, scope, await sha256Hex(canonicalRequest)].join('\n');
  const kDate = await hmac(encoder.encode('AWS4' + target.secretAccessKey), date);
  const kRegion = await hmac(kDate, target.region);
  const kService = await hmac(kRegion, 's3');
  const kSigning = await hmac(kService, 'aws4_request');
  const signature = hex(await hmac(kSigning, stringToSign));
  return `https://${target.host}${encodePath(target.path)}?${canonicalQuery}&X-Amz-Signature=${signature}`;
}

export function presignConfig(env: Env): R2Presigner | null {
  const e = env as unknown as Record<string, string | undefined>;
  const accountId = (e.R2_ACCOUNT_ID ?? '').trim(), bucket = (e.GIT_BUCKET ?? '').trim(), accessKeyId = (e.R2_ACCESS_KEY_ID ?? '').trim(), secretAccessKey = (e.R2_SECRET_ACCESS_KEY ?? '').trim();
  return accountId && bucket && accessKeyId && secretAccessKey ? { accountId, bucket, accessKeyId, secretAccessKey } : null;
}
export function lfsMode(env: Env): 'direct' | 'proxy' { return presignConfig(env) ? 'direct' : 'proxy'; }
export function presignObject(config: R2Presigner, method: 'GET' | 'PUT' | 'HEAD', key: string, expiresSeconds: number, now = new Date()): Promise<string> {
  return presign({ accessKeyId: config.accessKeyId, secretAccessKey: config.secretAccessKey, region: 'auto', host: `${config.accountId}.r2.cloudflarestorage.com`, path: `/${config.bucket}/${key}` }, method, expiresSeconds, now);
}
```

```js
// Large files (Git LFS) on the dashboard: the .lfsconfig snippet, usage and mode texts. Pure, so the tests cover them.
export function formatBytes(n) {
  const units = ['B', 'kB', 'MB', 'GB', 'TB'];
  let value = n, unit = 0;
  while (value >= 1024 && unit < units.length - 1) { value /= 1024; unit++; }
  const rounded = Math.round(value * 10) / 10;
  return `${Number.isInteger(rounded) ? rounded : rounded.toFixed(1)} ${units[unit]}`;
}
export function lfsConfigSnippet(origin, projectId) { return `[lfs]\n\turl = ${origin}/git/${projectId}.git/info/lfs\n`; }
export function lfsSummary(lfs) {
  if (!lfs || !lfs.objects) return 'No large files yet';
  return `${lfs.objects} ${lfs.objects === 1 ? 'object' : 'objects'} · ${formatBytes(lfs.bytes)}`;
}
export function lfsModeText(lfs) {
  return lfs && lfs.mode === 'direct' ? 'Large files go straight to R2, up to 5 GB each.' : `Large files move through Smith, up to ${formatBytes(lfs && lfs.proxyMaxBytes || 104857600)} each.`;
}
```

```ts
// Work machines do for large files (spec §8): fetch a copy of an object, restore a lost object to R2, drop a copy.
// Planned by the alarm (every switched-on, online machine with room holds every ready object, oldest first; a lost
// object goes back from any online holder), handed out on the machine's git/poll, four at a time, under a lease.
import { fail } from './http';
import type { NodeRow } from './workspace';
import type { LfsStore } from './lfs';

export type LfsTaskKind = 'fetch' | 'restore' | 'drop';
export type LfsTaskRow = { id: string; repo_id: string; oid: string; node_id: string; kind: LfsTaskKind; state: 'queued' | 'leased' | 'done'; lease_token: string | null; lease_expires_at: number | null; attempts: number; next_attempt_at: number; message: string; created_at: number; updated_at: number };
export const LFS_TASK_LEASE_MS = 120000;
export const LFS_TASKS_PER_POLL = 4;
export const LFS_PLAN_LIMIT = 50;
const RETRY_MS = (attempts: number) => Math.min(3600000, 60000 * 2 ** Math.min(attempts, 6));

export function nodeFreeBytes(node: NodeRow): number {
  if (!node.hosting) return 0;
  try { return Number((JSON.parse(node.hosting) as { free?: number }).free ?? 0) || 0; } catch { return 0; }
}
// Keeps large files here: active, a build machine, switched on, not draining, online.
export function lfsEligible(node: NodeRow, now: number, offlineMs: number): boolean {
  return Boolean(node.active) && node.purpose === 'build' && Boolean(node.host_lfs) && !node.draining && node.last_seen_at > now - offlineMs;
}
const online = (node: NodeRow, now: number, offlineMs: number) => Boolean(node.active) && node.last_seen_at > now - offlineMs;

export class LfsTasks {
  constructor(private readonly sql: SqlStorage) {}
  task(id: string): LfsTaskRow { const row = this.sql.exec<LfsTaskRow>('SELECT * FROM lfs_tasks WHERE id = ?', id).toArray()[0]; if (!row) fail(404, 'not_found', 'Task not found'); return row; }
  pendingFor(nodeId: string): boolean { return this.sql.exec<{ n: number }>("SELECT COUNT(*) AS n FROM lfs_tasks WHERE node_id = ? AND state IN ('queued', 'leased')", nodeId).one().n > 0; }
  private pending(kind: LfsTaskKind, repoId: string, oid: string, nodeId: string | null): boolean {
    return this.sql.exec<{ n: number }>(`SELECT COUNT(*) AS n FROM lfs_tasks WHERE kind = ? AND repo_id = ? AND oid = ? AND state IN ('queued', 'leased')${nodeId ? ' AND node_id = ?' : ''}`, ...(nodeId ? [kind, repoId, oid, nodeId] : [kind, repoId, oid])).one().n > 0;
  }
  queue(kind: LfsTaskKind, repoId: string, oid: string, nodeId: string, now: number, delayMs = 0): LfsTaskRow | null {
    if (this.pending(kind, repoId, oid, nodeId)) return null;
    const id = crypto.randomUUID();
    this.sql.exec("INSERT INTO lfs_tasks (id, repo_id, oid, node_id, kind, state, next_attempt_at, created_at, updated_at) VALUES (?, ?, ?, ?, ?, 'queued', ?, ?, ?)", id, repoId, oid, nodeId, kind, now + delayMs, now, now);
    return this.task(id);
  }
  // A machine's poll: up to LFS_TASKS_PER_POLL leased at once; `leaseTokens` were minted before the transaction.
  poll(node: NodeRow, leaseTokens: string[], now: number): LfsTaskRow[] {
    const leased = this.sql.exec<{ n: number }>("SELECT COUNT(*) AS n FROM lfs_tasks WHERE node_id = ? AND state = 'leased'", node.id).one().n;
    const room = Math.min(leaseTokens.length, LFS_TASKS_PER_POLL - leased);
    if (room <= 0) return [];
    const next = this.sql.exec<LfsTaskRow>("SELECT * FROM lfs_tasks WHERE node_id = ? AND state = 'queued' AND next_attempt_at <= ? ORDER BY created_at LIMIT ?", node.id, now, room).toArray();
    return next.map((row, i) => {
      this.sql.exec("UPDATE lfs_tasks SET state = 'leased', lease_token = ?, lease_expires_at = ?, attempts = attempts + 1, updated_at = ? WHERE id = ?", leaseTokens[i], now + LFS_TASK_LEASE_MS, now, row.id);
      return this.task(row.id);
    });
  }
  held(id: string, node: NodeRow, leaseToken: string, now: number): LfsTaskRow {
    const row = this.task(id);
    if (row.node_id !== node.id || row.lease_token !== leaseToken) fail(409, 'stale_task', 'This task is not yours');
    if (row.state !== 'leased' || (row.lease_expires_at ?? 0) <= now) fail(409, 'stale_task', 'This task’s lease has ended');
    return row;
  }
  settle(id: string, ok: boolean, message: string, now: number): LfsTaskRow {
    const row = this.task(id);
    if (ok) this.sql.exec("UPDATE lfs_tasks SET state = 'done', message = ?, lease_token = NULL, lease_expires_at = NULL, updated_at = ? WHERE id = ?", message.slice(0, 300), now, id);
    else this.sql.exec("UPDATE lfs_tasks SET state = 'queued', message = ?, lease_token = NULL, lease_expires_at = NULL, next_attempt_at = ?, updated_at = ? WHERE id = ?", message.slice(0, 300), now + RETRY_MS(row.attempts), now, id);
    return this.task(id);
  }
  // Leases that ran out go back to the queue; fetches for machines no longer switched on (or gone) are dropped, and
  // every task of a machine that was removed; drops survive a switch-off (that is how the machine clears its store).
  expire(now: number, nodes: NodeRow[]): void {
    this.sql.exec("UPDATE lfs_tasks SET state = 'queued', lease_token = NULL, lease_expires_at = NULL, next_attempt_at = ?, updated_at = ? WHERE state = 'leased' AND lease_expires_at <= ?", now, now, now);
    for (const row of this.sql.exec<LfsTaskRow>("SELECT * FROM lfs_tasks WHERE state IN ('queued', 'leased')").toArray()) {
      const node = nodes.find(n => n.id === row.node_id);
      if (!node || !node.active || (row.kind === 'fetch' && !node.host_lfs)) this.sql.exec('DELETE FROM lfs_tasks WHERE id = ?', row.id);
    }
    this.sql.exec("DELETE FROM lfs_tasks WHERE state = 'done' AND updated_at <= ?", now - 86400000);
  }
  // Fetches: every eligible machine with room (free minus what is already queued for it stays above the reserve) takes
  // the oldest ready objects it lacks. Restores: a lost object with an online holder goes back from that holder.
  plan(now: number, nodes: NodeRow[], offlineMs: number, store: LfsStore, reserveBytes: number): number {
    let queued = 0;
    const ready = store.ready();
    for (const node of nodes.filter(n => lfsEligible(n, now, offlineMs))) {
      const reported = nodeFreeBytes(node);
      if (reported <= 0) continue;   // no hosting report yet
      const held = new Set(store.heldRows(node.id).map(r => r.repo_id + '/' + r.oid));
      const queuedBytes = this.sql.exec<{ b: number | null }>("SELECT SUM(o.size) AS b FROM lfs_tasks t JOIN lfs_objects o ON o.repo_id = t.repo_id AND o.oid = t.oid WHERE t.node_id = ? AND t.kind = 'fetch' AND t.state IN ('queued', 'leased')", node.id).one().b ?? 0;
      let free = reported - queuedBytes, count = 0;
      for (const row of ready) {
        if (held.has(row.repo_id + '/' + row.oid) || this.pending('fetch', row.repo_id, row.oid, node.id)) continue;
        if (free - row.size < reserveBytes) break;
        if (this.queue('fetch', row.repo_id, row.oid, node.id, now)) { free -= row.size; queued++; if (++count >= LFS_PLAN_LIMIT) break; }
      }
    }
    for (const row of store.lostRows()) {
      if (this.pending('restore', row.repo_id, row.oid, null)) continue;
      const holder = store.holders(row.repo_id, row.oid).map(id => nodes.find(n => n.id === id)).find(n => n && online(n, now, offlineMs));
      if (holder && this.queue('restore', row.repo_id, row.oid, holder.id, now)) queued++;
    }
    return queued;
  }
  // Whether the reserve blocks every further fetch to this machine right now (for its card).
  full(node: NodeRow, reserveBytes: number): boolean { const free = nodeFreeBytes(node); return free > 0 && free < reserveBytes; }
}
```

```ts
// The machine side of a large-file task (lfs-tasks.ts): a fetch streams the object down, a restore sends it back
// (straight to R2 over a presigned PUT when enabled, else through this Worker), and the completion is recorded.
// Every step is authorised by the workspace Durable Object against the task's lease, like git-task-route.ts.
import { fail, json, readBody, HttpError } from './http';
import { nodeAction as linkedNodeAction, routedLeaseToken } from './linked-nodes';
import { storeBody, hex } from './r2-store';
import { presignConfig, presignObject } from './r2-presign';
import { LFS_EXPIRES_SECONDS } from './lfs';

const NODE_LFS_TASK = /^\/api\/v2\/workspaces\/([a-f0-9]{64})\/lfs\/task\/([a-f0-9-]{36})\/(body|target|object|complete)$/;
type View = { kind: 'fetch' | 'restore' | 'drop'; key: string; size: number; oid: string; repoId: string };
function bearer(request: Request): string { const h = request.headers.get('Authorization') ?? ''; return h.startsWith('Bearer ') && h.length < 512 ? h.slice(7) : ''; }

export async function handleNodeLfsTask(request: Request, env: Env): Promise<Response | null> {
  const match = NODE_LFS_TASK.exec(new URL(request.url).pathname);
  if (!match) return null;
  const [, workspaceId, taskId, step] = match;
  const token = bearer(request);
  // A completion carries its lease in the body (the agent's Post sends no extra headers); the other steps in the header.
  const body = step === 'complete' ? await readBody(request, 65536) : {};
  const leaseHeader = request.headers.get('X-Smith-Lease-Token') ?? (typeof body.leaseToken === 'string' ? body.leaseToken : '');
  const routed = routedLeaseToken(leaseHeader);
  const leaseToken = routed?.token ?? leaseHeader;
  const act = (action: string, extra: Record<string, unknown>) => linkedNodeAction(env, workspaceId, token, action, { ...extra, taskId, leaseToken: routed ? leaseHeader : leaseToken });
  const bucket = (env as { GIT?: R2Bucket }).GIT;
  try {
    if (!bucket) fail(503, 'no_bucket', 'This coordinator has no repository bucket');
    const viewed = await act('lfs-task-view', {});
    if (!viewed.ok) return viewed;
    const view = await viewed.json() as View;
    if (step === 'body') {
      if (request.method !== 'GET') fail(405, 'method', 'GET the object');
      if (view.kind !== 'fetch') fail(409, 'not_fetch', 'This task does not download an object');
      const object = await bucket.get(view.key);
      if (!object) fail(503, 'object_unavailable', 'The object is no longer in the bucket');
      return new Response(object.body, { headers: { 'Content-Type': 'application/octet-stream', 'Content-Length': String(object.size), 'Cache-Control': 'private, no-store' } });
    }
    if (step === 'target') {
      if (request.method !== 'POST') fail(405, 'method', 'POST for the upload target');
      if (view.kind !== 'restore') fail(409, 'not_restore', 'This task does not restore an object');
      const signer = presignConfig(env);
      return json({ href: signer ? await presignObject(signer, 'PUT', view.key, LFS_EXPIRES_SECONDS) : null, size: view.size });
    }
    if (step === 'object') {
      if (request.method !== 'PUT') fail(405, 'method', 'PUT the object');
      if (view.kind !== 'restore') fail(409, 'not_restore', 'This task does not restore an object');
      const stored = await storeBody(bucket, view.key, request, Math.max(view.size, 1), { sha256: view.oid });
      if (stored.size !== view.size) { try { await bucket.delete(view.key); } catch { /* best effort */ } fail(422, 'size_mismatch', `Uploaded ${stored.size} bytes; the object is ${view.size} bytes`); }
      return json({ stored: stored.size });
    }
    if (request.method !== 'POST') fail(405, 'method', 'POST the completion');
    let verified = false;
    if (view.kind === 'restore' && body.ok === true) {
      // Whichever way it arrived, the object in R2 must hash to its id before the record calls it ready.
      const object = await bucket.get(view.key);
      if (!object) fail(409, 'not_stored', 'The object did not arrive in the bucket');
      if (object.size !== view.size) { try { await object.body.cancel(); } catch { /* unread */ } try { await bucket.delete(view.key); } catch { /* best effort */ } fail(422, 'size_mismatch', `Stored ${object.size} bytes; the object is ${view.size} bytes`); }
      const digest = new crypto.DigestStream('SHA-256'); await object.body.pipeTo(digest);
      if (hex(await digest.digest) !== view.oid) { try { await bucket.delete(view.key); } catch { /* best effort */ } fail(422, 'hash_mismatch', 'The restored object does not match its id'); }
      verified = true;
    }
    return await act('lfs-task-complete', { ok: body.ok, message: body.message ?? '', verified });
  } catch (error) {
    if (error instanceof HttpError) return json({ error: { code: error.code, message: error.message } }, error.status);
    console.error(JSON.stringify({ event: 'lfs_task_failed', type: error instanceof Error ? error.name : 'unknown' }));
    return json({ error: { code: 'internal_error', message: 'Request failed' } }, 500);
  }
}
```

```js
  const free = machine.freeBytes > 0 ? `${formatBytes(machine.freeBytes)} free` : 'free space unknown';
```
